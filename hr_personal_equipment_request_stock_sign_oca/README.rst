Generate the Signature Request when a Picking for a Personal Equipment
Request is completed.

Since the picking is confirmed after the request creation, only valid
allocations are included in the Signature Request.

Configuration
=============

If you want to show the Lot/Serial number in the generated Signature
Request:

1. Go to Employees > Configuration > Settings
2. Enable "S/N in PPE Request Report"
